# Authentication Error-State Exports

Task IDs: `UX-02` / `UX-04`

These exported SVGs provide responsive authentication UX states for review and handoff.

## Included assets

- `Login+Error/` — desktop login default, focus, filled, loading, inline-error, authentication-failure, locked, and success states.
- `Forgot_Pass+Error/` — registration fields, password strength, required/mismatch/duplicate errors, loading, email entry, verified state, and wrong-OTP state.
