# AXIVON ONE Test Suite

## Structure
- `unit/`: Unit tests for utilities, validators, models, and UI components.
- `integration/`: API route and repository integration tests.
- `e2e/`: End-to-end integration workflows mapped to Core modules.
- `fixtures/`: Shared test data fixtures and mock payloads.

## Task-Based Test Mapping
All tests should reference the corresponding Task ID (e.g., `AX1-CORE-001-BE-05.spec.ts`).
