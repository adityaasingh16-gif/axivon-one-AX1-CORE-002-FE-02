# AXIVON ONE Developer Setup & Guidelines

## Prerequisites
- Node.js >= 20.x
- npm >= 10.x (or pnpm / yarn)
- TypeScript >= 5.3

## Getting Started
1. Clone repository:
   ```bash
   git clone https://github.com/axivon-technologies/axivon-one.git
   ```
2. Copy environment template:
   ```bash
   cp .env.example .env
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run Typecheck:
   ```bash
   npm run typecheck
   ```
