# AXIVON ONE Phase 1 Authentication Assets

Task ID: `AX1-CORE-001-UX-01`

This folder contains the exported authentication UI states for the Phase 1 UX task:

- `login/` — default, focus, filled, loading, inline-error, authentication-error, locked, success, and desktop variants.
- `forgot-password/` — exported forgot-password and registration state screens. Ambiguous source filenames are normalized as `exported-state-XX.svg`.
- `style-guide/` — supplied style guide export.

Figma reference: https://www.figma.com/files/team/1677980873933661794/folder/649923846?fuid=1677980872332194482

The Community kit/Figma file remains the visual source of truth. These files are versioned exports for review and handoff; they do not replace the Figma document. No authentication code, credentials, or secrets are included.
