# AXIVON ONE UI/UX Design Documentation

## Directory Structure
- `design-system/`: Design tokens, typography, color palettes, and component library specs.
- `core/`: Module-specific design assets and user flows for all 12 Core Platform modules.
- `developer-handoff/`: Handoff specifications, assets, and token mappings for frontend developers.
- `design-qa/`: UI/UX review criteria, audit checklists, and accessibility compliance.
