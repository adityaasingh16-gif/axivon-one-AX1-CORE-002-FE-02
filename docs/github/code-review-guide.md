# AXIVON ONE — Code Review Guide

## Reviewer Checklist
- [ ] Does the PR contain only code relevant to the specified Task ID?
- [ ] Are reusable components/contracts used instead of duplicated logic?
- [ ] Is TypeScript strict mode respected (no implicit or unnecessary `any`)?
- [ ] Are sensitive data/credentials completely absent?
- [ ] Are errors handled gracefully with standard API envelopes?
